# 岩手医科大学 2025年度 物理

## 編集元と公開境界

- パッケージ：`iwate-medical-2025-general-physics`
- 原稿：別プロジェクトの `projects/universities/iwate-medical/past-exams/working/2025/general/first-stage/physics`。
- 問題は `source-html/generated/public-candidate/questions` の意味構造を取り込む。解説は問題から独立に導出し、内部資料の解答番号と照合。内部解説の本文や画像は複製していない。
- 現在の依頼でステージング掲載は許可されている。本番公開・権利審査・編集承認の完了を意味しない。各ページのnoindexとレビュー状態を維持。

## 再生成

リポジトリルートで `node frontend/scripts/build-iwate-2025-physics-figures.mjs` を実行すると、独自SVG 10点と登録マニフェストが再生成される。質問用9図、解説用の球面幾何1図。解説では軌道図と電流グラフを再利用する。

問題の更新は `past-exam-question-importer` スキルの標準コマンドを使う。パッケージに対応するオーバーライドに加え、`--figure-manifest frontend/src/data/pastExamFigures/iwate-medical-2025-general-physics.json` を指定。時間は `理科2科目 合計120分`。図の対応が欠けた場合は失敗させ、未掲載のまま進めない。

分析更新は `past-exam-analysis-publisher` スキルのコマンドを使う。HTMLは `preview-html/public-preview/index.html`、検証用メタデータは `analysis.json` と `derived.json`。抽出後は `pastExamAnalysisSources` の短い編集文と分離して保持する。

`frontend` で `npm run build` を実行すると、ローカルの解説原稿・分析スナップショットからページを再生成する。ビルド時に別プロジェクトへのアクセスは不要。

## 物理固有の確認

- 3大問・24小問、解答番号1〜24。科目75点、4科目合計350点、公式時間は理科2科目120分。物理60分は分析上の仮配分。既存の数学ページの条件は変更しない。
- 難易度別の小問数：5・5・11・3。推定配点：15・15・34・11点。大学公表の小問配点ではない。
- 苦手層の元モデルは全問走査48.4分を含むため編集確認中の注記を表示。目標27点の選択は初期優先枠への単純追加ではなく、第1問問1を第3問問1・問4に入れ替える。実行時間は小問ごとに倍率適用・丸め後に合計する。
- 軌道の焦点位置、分離前後の質量・速度の正方向、コイルの対応端子、電流グラフの区間と符号、球面の上下関係を式と照合した。
- 第3問問5は光軸近傍の近似を明示。小さいすき間だけからすべての長さ比が小さいと断定しない。

## 検証範囲

`npm run past-exam:physics:test` は24問の対応、図の登録・参照、KaTeXの構文、分析の配点・時間・前提依存、数値的不変条件、共通ナビゲーションを検証する。SEO・既存数学のUI・解説生成・分析生成のテストも併用する。

独自SVGはラスタライズして図そのものを確認した。ブラウザ画面や印刷PDFの実レンダリング検証とは区別する。自動検証は説明文の論理や編集承認を代替しない。出力の要求、導出の順序、符号・単位、代入先、図と式の対応を別途読み直す。
