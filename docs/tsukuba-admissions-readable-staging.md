# 筑波大学入試情報の読みやすさ改善（ステージング見本）

2026年10月10日のユーザー指示により、筑波大学の復元済み入試情報を整形し、stagingへ反映する。4つの校閲・整形チャットを作る前の見本であり、今回の指示には本番反映や新規チャット作成を含まない。

## 表示方針

- 大学概要より先に2027年度の入試情報を配置する。
- 記事冒頭の「この記事の要点」は、一般枠の募集人数・試験日、配点と筆記・面接、推薦一般の人数・試験日・共通テスト不要を3項目で示す。資料確認の報告や確認日は要点に含めない。
- 冒頭に「入試方式・募集人数・出願・試験日」の一覧を置く。スマホは方式ごとのカード表示にする。
- 募集人数、日程、出願資格、試験内容、会場、併願の注意を分ける。合格発表や成績提出期限は日程欄に置く。
- 教科別配点は数値の比較表にする。一般枠の配点を地域枠へ転用しない。
- すべて必要な資格条件は箇条書きにし、AND/OR、例外、必着、時刻、未公表の範囲を保持する。
- 文の先頭を強調し、補足を段落に分ける。表・各項目には出典番号や外部リンクを付けず、表の外の小さな「情報ソースはこちら」から末尾の公式資料一覧を開けるようにする。
- 表で示した点数や人数を、その直下で文章として繰り返さない。教科別配点と総合計は表にまとめ、個別理科の選択・換算方法・予定人数の認可条件など、固有の条件だけ補足として残す。
- IBの7月・10月合計人数、地域枠の合計人数を各方式の独立した人数として計上しない。
- 公開本文に「転用しない」「流用しない」等の編集指示、監査報告、掲載対象を説明する作業メモを出さない。未公表の項目は、未公表の範囲と「募集要項の公開後に更新します」等の受験生への案内にする。出願資格・例外・試験当日の指示は保持する。
