# 2027年度 私立医学部「一般選抜・通常の共通テスト利用選抜以外」外部補完レポート

- 確認日: 2026-08-04
- 対象年度: 2027年度入試
- 対象: 私立大学医学部医学科31大学
- 対象方式: 2027年3月卒業見込みの高校生が出願できる、一般選抜・通常の大学入学共通テスト利用選抜以外の方式
- 参照KB: `C:\---hp\shidai-igakubu-gokaku-dokuhon\medical-admissions-ai-html-kb`

## 1. このレポートの位置づけ

本レポートは、既存KBのHTMLエンティティページと検索用JSONLを起点に、KBに方式実体・出願資格・日程・公開状態がない、古い、または不十分だった項目を、2027年度の大学公式ページ・公式募集要項・公式PDFで補完した記録です。

公開ページの正規データは `frontend/src/data/privateMedicalSpecialAdmissions2027.ts` に分離しています。本レポートは調査証跡であり、ここに日程を重複実装するものではありません。

## 2. 判定ルール

1. KBの検索用JSONLは候補抽出にのみ使い、最終判断はKBのHTMLエンティティページと大学公式原典で行いました。
2. 方式名だけで採否を決めず、2027年3月卒業見込みの高校生が公式出願資格を満たし得るかを確認しました。
3. 2026年度以前の日程・募集人員・出願資格を2027年度値へ転用していません。
4. 2027年度の詳細要項が未公表の項目は、公式概要で確認できた範囲だけを掲載し、現役可否を断定できない場合は「未確認」としました。
5. 推薦型・総合型等として独立して実施され、選考の一部に大学入学共通テストを課す方式は対象に含めました。
6. 名称が特別選抜等でも、実質的に一般選抜または通常の共通テスト利用選抜として実施される方式は対象外としました。
7. 学士・編入・大学在学者・社会人だけを対象とし、現役高校生が出願できない方式は除外しました。
8. 同一名称に見えても公式に別方式として掲載される県別地域枠等は、方式別に保持する方針です。

| 募集要項公表済み | 対象方式の2027年度完成版要項または同等の公式詳細ページを確認できた |
| 一部公表 | 一部方式は完成要項で確認できるが、別方式の詳細・認可・対象校向け条件等が未公表 |
| 公式概要公表 | 2027年度の方式・予定・日程等は確認できるが、完成版要項が未公表 |
