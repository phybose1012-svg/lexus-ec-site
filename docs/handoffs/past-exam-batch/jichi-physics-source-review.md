## 1. 問題20の必要十分条件：始動と通過を区別

問題p007、解説p007、major-question-16。本文の `p>2aμ′` は、いったん滑り始めて右向きに運動する小球がOを正の速さで通過する条件です。`k=mg/a`、`kp²/2>μ′mgp` から導出されます。

一方、Pで静かに離して動き出すには `kp>μmg`、すなわち `p>aμ` が必要です。例えばa=1、μ′=0.2、μ=0.8、p=0.5なら、現行選択肢エを満たすのに始動しません。したがって静止から全過程が起こる条件は、特段の前提がなければ `p>max(aμ,2aμ′)` です。

原本p007の問題文にも「pとμ′」「必要十分条件」とあり、単純な転記ミスと決めつけて問題を書き換えてはいけません。始動が前提とされている読み方、冒頭/注記に追加条件がないかを科目責任者へ確認し、問題・解説に必要な限定を付してください。根拠未確定ならissueを開いたままにし、元の答えエを別の選択肢へ勝手に変えないこと。Lexus側は当該問題群に注意書きを残しています。

## 2. 問題18：二つの実験の力を足す理由

問題p006、解説p006、major-question-14。現行は「鉛直方向の力のつりあい」だけで `9.8m=40+9.0` としています。40Nと9.0Nは同時に加えた二力ではありません。

左端から重心までx、長さl=1.0m、重さWとして、右端を40Nで持ち上げる場合は左接地点まわりで `40l=Wx`、左端を9Nで上げる場合は右接地点まわりで `9l=W(l−x)`。足して `W=49N`、m=5.0kgと示せます。小さく傾けた図でも両モーメントの腕に同じcosθが掛かって消えることを説明できます。数値の答えは変更不要。異なる実験の力をそのまま同一物体の力の図へ並べないでください。

## 3. 問題23〜25：動摩擦下の振動中心を説明

解説p008、major-question-16。単に「単振動の中心だからPQの中点」だけでは、自然長位置Oと振動中心O′がなぜ異なるかが分かりません。Oを原点、右正、右向き運動中の `m x''=−kx−μ′mg=−k(x+aμ′)` を明記し、`x(O′)=−aμ′=(q−p)/2`、振幅 `(p+q)/2` とつなげてください。P→Qの間は摩擦の向きが一定なのでこの中心の単振動となり、端から反対端まで半周期です。往復全体を同じ中心の単振動と言わないこと。Qから再始動する条件は問21の `kq>μmg` として区別します。
