## 2. 第1問：円弧通過と最高点到達の条件（解答1〜3）

learnerのアは円弧全体から離れない上限、ウ・エは半円筒内の条件を扱う。エで `h≧5a/2` だけを求めて終わると、手前の円弧を通過できるかが説明されない。原本側もこの確認を省いているため、転記の誤りではなく学習者版の補足として記録する。

独立検算：外側 `N/(mg)=3cosθ−2h/a+2d/a`、内側 `N′/(mg)=2h/a−2−3cosθ′`。ウ・エのd=5a/4、cosφ=8/9では、円弧通過範囲は `9a/4<h≦31a/12`。ウのh=7a/3も、エの最小h=5a/2もこの範囲内。エでは内側の抗力がEで最小になる理由も明示する。オ・カはd=2aで `3a<h≦10a/3` と `h≧5a/2` の共通範囲になる。

ウは `N′=0` への代入直後にcosθ′=8/9へ飛ばず、`0=14/3−2−3cosθ′` の1段を示す。境界のN′=0と、それより先では負の抗力を要求して離れることを区別する。外側θは鉛直からの非負の角の大きさとして両側に使うことを定義する。

## 3. 第2問：熱量の符号と計算の橋渡し（解答3・4）

- イ：learnerは断熱仕事の結論に圧縮している。`Q=ΔU+W`、断熱なら `0=C_V(b−a)+W_AB` と定義・代入対象を1回明示。B→Cのみ吸熱、D→Aは放熱、定積区間の仕事0であることを示して分母と分子を説明する。
- ウ・エ：A→BとC→Dの熱量だけを足せる理由は、残るB→C・D→Aが断熱だから。A→Bが放熱なので `C_p(b−a)<0`、吸熱の分母は `C_p(d−c)>0`。符号付き熱量と放出熱の正の大きさを区別する。
- オ：I〜IIIで何が変わるかを明記し、IIIは `Q_in=C_p(c−b)`、`Q_out=C_V(d−a)`、残りは断熱と整理する。元の「同様に」だけで済ませない。
- キ：与式から `Q_AB/Q_CD=b/d` を作ってから効率へ代入する。カのΔU=0の説明はlearnerには復元されているので、重複して式を増やさない。

## 4. 第3問(2)(3)：明暗が等間隔という根拠の不足（解答4・5）

原本・learnerは明線、暗線、明線の並びから「等間隔なのでm0も暗線」と結論する。角度のsinとスクリーンのtanの違いがあり、(4)で初めて小角近似を与える設問に対し、正確な等間隔を一般に断定するのは不適切。

最短の根拠は、元のm1で隣接スリットの伝播による位相差が2πであること。そこで完全に打ち消し合うため平板の二群間位相差はπ（mod 2π）、0≦α<2πからα=π。直進方向では伝播位相差0なので同様に打ち消し合う、と順に説明する。

(3)も「最初からπ」「最寄りなので半波長」だけでなく、隣接スリット間の伝播位相と平板の位相を合わせた強め合いの条件を示す。最小正角でd sinθ_B=λ/2となる。同じ群の2d間隔では位相差2πになることも確認できる。問題から決まらない平板厚やスリット数を新条件として作らない。

## 5. 第3問(4)(5)：近似記号と主解法の脱落（解答5）
