### 3. 第2問(6)：四面体の高さを結論だけにしない（解答3）

learnerの「底面の高さOH=2、高さCS=2を得ます」は導出を飛ばしすぎている。4面合同から対辺の長さ、垂線の足H/Sと補助点Tの定義、OH、CSを求める過程を保持する。図だけで高さ2が証明されたとしない。

検算用座標：O=(0,0,0), A=(2√2,0,0), B=(1/√2,3/√2,0), C=(3/√2,1/√2,2), S=(3/√2,1/√2,0), T=(√2,0,0), H=(√2,√2,0)。OA²=CB²=8、OB²=CA²=5、AB²=CO²=9。AS=1、SB=2、ST=1、CT²=5、CS=2。CSはABとSTの両方に垂直なので底面への高さ。底面積3、体積2。Tで直角と誤認しないこと。

### 4. 第2問(7)(9)(10)：短くしすぎた計算の橋渡し（解答3〜5）

- (7)：p>0を確認。`V/π=∫(log p+log x)^2 dx`から平方完成へ飛ぶ前に、交差項の積分 `∫_1^2 log x dx=2log2−1` とlog pの2次式を示す。pに依存しない定数の省略は目的を明示すれば可能。結論p=e/4。平方完成で最小化できるので、増減表を無理に追加しない。
- (9)：因子 `4u(u−1)(u+1)=0` と定義域の記述はlearnerにもある。ただしcos((x−y)/2)で割れる理由、和積公式から(x+y)/2=π/4へ至る橋渡しがない。0≦(x−y)/2<π/2、0<(x+y)/2<πを示し、u=sin((x−y)/2)の範囲から±1を除外する。答えはx=y=π/4。
- (10)：PQ=4√3へ飛ばず、中心間8と半径差4からPQ²=8²−4²を示す。相似な三角形RPO₁とRQO₂を明記し、PR/(PR+PQ)=2/6を導く。PR=2√3。
- (10)の原本問題文は「共通接線」とあり、異なる接点の指定が明示されていない。2円の相互接点での共通接線ならP=Q=Rとなる退化例もある。原本解図は共通外接線を意図している。勝手に問題へ条件を追加せず、原本確認と編集責任者の判断をopen issueへ残す。サイトの独立図は「異なる接点P・Qをもつ共通外接線の場合」と限定している。
