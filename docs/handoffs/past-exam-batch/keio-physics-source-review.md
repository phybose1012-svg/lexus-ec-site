## 4. 原解答そのものの符号・単位・論理への注記

- 原解答p06の逆向き励磁コイルで、式③の直前にある2行の変形を比較してください。初めの展開のsin(2ωt)項は負、cos(ωt)sin²(ωt)項は正ですが、次行ではこの2項の符号が変わっています。全体符号反転でもありません。最終加算信号 `−6bωNSH0H1²sin(2ωt)` は独立微分に一致します。正本の忠実転記層には誤記の所在を残し、学習者版には根拠付きの修正式を出すこと。canonicalが当該中間行をどこまで保持しているかをまず比較してください。

## 5. III：気体・断熱変化の条件と結論

- γが比熱比であること、微小変化(p+Δp,T+ΔT)、2次以上を無視すること、与えられた `(1+x)^y≈1+yx` の条件を復元してください。
- III(a)はp≈2.9×10⁴ Pa、n≈1.0×10⁻⁴ mol、(b)はp≈7.5×10³ Pa、n≈2.9×10⁻⁵ molまで回答します。現状は(a)の最終値と(b)のnが抜けています。80℃で全量気体か、40℃で凝縮するかを飽和圧との比較で説明すること。
- III(c)のA=1−γ、B=1−1/γを結果だけにせず、pV=nRTの代入からポアソン式、一次近似へ橋渡ししてください。
- III(d)のC=ρgはすでにあります。(e)の代入先と最終C、(f)の最終Dを明記し、単に「代入」やΔTの式に埋めたままで終わらないこと。Mのg/molからkg/molへの換算を含めます。(g)は100mで約−1.013K→−1.0Kに一致します。
- III(h)では大気と気塊が同じ平均分子量、同じ高度では圧力が等しいという条件を示し、周囲の温度変化が気塊の温度変化より大きいという関係を密度／力から導きます。上記の不要な単調減少の仮定を置かないでください。
- III(i)の原問題は水滴の有無の比較で、D′を定義していません。問題側に独自記号を加えず、解説で必要なら湿潤／乾燥のDを明示定義します。凝縮の潜熱と温度低下の緩和を説明し、`D\prime`等の不適切なTeXも修復してください。
