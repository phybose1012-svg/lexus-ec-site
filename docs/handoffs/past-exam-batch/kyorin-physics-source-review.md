## 検出した修復事項（ページ番号はパッケージ内）

1. **問題p3／第Ⅱ問ウ・カの解答群。** 最初のstructured_listの⑤が `μ/2` になっていますが原本は `π/2`。さらに直前の「ウ、カの解答群」の見出しが脱落。共通選択肢を別の設問群と使い回さないこと。
2. **問題p3／第Ⅱ問(b)のキ。** 原本は `x_A = [キ] mg/k + L`。現在は `L + [キ] αmg/k` で空欄外にαが余分に加わっています。正しい係数はαμ、原本選択番号⑦。式・選択肢・解答キーを同時に照合してください。
3. **同p3／キ・ケの解答群が別の群へ置換。** 正しい①〜⑨⓪は `1/2, 2, α, μ, μ', −μ', αμ, −αμ, αμ', −αμ'`。現行はウ・カの群をコピーしており負号が全て欠落しています。ケの正解⓪は `−αμ'`、動摩擦力は負方向です。解答番号だけ直して辻褄を合わせないこと。
4. **問題p4／シ・スの解答群⑦。** 現行 `μ'/(1+α)`、原本は `α/(1+α)`。他9選択肢も再照合してください。
5. **解答p5／重心の式。** 原本 `a=αb` が reconstructionでは `α=a:b` に変化。GA=a、GB=bから `mg a=αmg b`、したがって `a:b=α:1`。原本転記を戻し、learnerにも比が導かれる一段を補足すること。
6. **原解答p4／静止条件の論理（原本にも疑義）。** `N_B>0` と `f'_B>f_A` を結ぶ記述は、その直前の `f'_B+N_B=f_A` と符号が逆。Bが壁に触れていてもN=0の場合があります。張力最大値と最大静止摩擦力を比べる説明へ整理する必要があります。一般的な静止可能条件は `k(L−x0)≦μαmg` で、原本の選択肢には `>,<,=` しかなく解答は `x0>L−μαmg/k`。等号でも静止が可能な限界をどう扱うかは原本の不備として明示・編集責任者確認にしてください。設問・答えを黙って変更しないこと。
7. **原解答p5／加速度の符号（原本にも疑義）。** `x_A−x_B>L` だけで `a_B>0` と断定していますが、正方向移動中のBは `a_B=k(r−L)/(αm)−μ'g`。伸びが `μ'αmg/k` 未満ならaBは負。ばね力の向きと合力・加速度を区別し、learnerにこの誤説明を移さないこと。
8. **原解答p6／相対運動の中心（原本にも疑義）。** `r''=−ω'^2(r−L)+μ'g` の定数を単に消して中心をLとしています。正しくは `ω'^2=(1+1/α)k/m`、`r_eq=L+μ'g/ω'^2`、`X=r−r_eq` なら `X''=−ω'^2X`。相対速度の角振動数は原本の答えと同じですが、位置の中心は異なります。learner p6は差し引く式ごと省略して結論だけなので、前提「両球とも正方向運動中」とともに説明を補完してください。
9. **全learnerの途中式・理由の欠落。** 原解答9ページ約193ブロックに対しlearnerは大きく要約されています。特にI(b) J→MeV、I(c)反応質量差とエネルギーの和・運動量保存の代入、I(d)与えられた常用対数で39時間となる式、II(a)初期位相→力の符号→絶対値と周期、II(b)重心加速度と相対座標の導出、II(c)初期ばねエネルギー−W→最終振幅、III(2a)仮の開放解が逆バイアスを満たす確認、III(2c)閉回路の式を作って連立する工程、III(3)抵抗変更後の式・未知数の消去を復元してください。「代入すると」「連立すると」だけで済ませず、代入元・代入先・消去結果を示すこと。余計な式の水増しは不要ですが再現に必要な橋渡しは残すこと。
